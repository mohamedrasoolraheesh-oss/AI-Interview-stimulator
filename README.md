# 🚀 AI Interview Simulator

> **Practice Smarter. Interview Better. Get Hired.**

An AI-powered interview platform that simulates real technical and HR interviews using Generative AI. It helps students, job seekers, and professionals build confidence through personalized interview sessions, intelligent feedback, and performance analysis.

Designed to bridge the gap between learning and real-world interviews, this project provides an interactive environment where users can practice anytime, improve communication skills, and prepare for top tech companies.

---

## ✨ Why AI Interview Simulator?

Preparing for interviews can be stressful and inconsistent. This platform acts as a **24/7 AI Interviewer**, allowing users to practice in a realistic environment while receiving instant, AI-generated feedback to continuously improve.

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/AI-Interview-Simulator.git
```

### Navigate into the project

```bash
cd AI-Interview-Simulator
```

### Install frontend dependencies

```bash
npm install
```

### Install backend dependencies

```bash
pip install -r requirements.txt
```

### Start the frontend

```bash
npm run dev
```

### Start the backend

```bash
python main.py
```

## 🎯 How It Works

1. Choose your interview category.
2. AI generates interview questions.
3. Answer each question naturally.
4. Receive detailed AI-generated feedback.
5. Review strengths and improvement areas.
6. Repeat until you're interview-ready.
